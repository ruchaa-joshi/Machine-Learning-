# Linear and Logistic Regression

Regression algorithms are used in Machine Learning to make predictions from data. Linear Regression predicts continuous numerical values, while Logistic Regression predicts the probability of a category, commonly for binary classification.

## Key Concepts

- **Linear Regression:** Models the relationship between input features and a continuous target variable.
- **Logistic Regression:** Estimates class probabilities and assigns observations to categories.
- **Train-Test Split:** Divides data into training and testing sets to evaluate model performance.
- **Model Evaluation:** Measures prediction quality using appropriate metrics.
- **Data Visualization:** Uses scatter plots to compare actual and predicted values.

## Evaluation Metrics

**Linear Regression**
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- R² Score

**Logistic Regression**
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- Classification Report

## Dataset

- **Source:** Synthetic data generated using NumPy.
- **Linear Regression:** One input feature and a continuous numerical target.
- **Logistic Regression:** One input feature and a binary target with classes 0 and 1.
- **Purpose:** Demonstrate regression, classification, prediction, and model evaluation.

## Typical Workflow

1. Generate sample datasets and visualize the data.
2. Split each dataset into training and testing sets.
3. Train Linear Regression and Logistic Regression models.
4. Generate predictions on test data.
5. Evaluate performance using suitable metrics.
6. Visualize actual and predicted results.

## Tools

Python, NumPy, Matplotlib, and Scikit-learn.

## Conclusion

Linear Regression is suitable for predicting continuous numerical values, whereas Logistic Regression is used for classification. Evaluation metrics help assess model performance and understand prediction errors.
