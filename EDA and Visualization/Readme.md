# Exploratory Data Analysis (EDA)

Exploratory Data Analysis (EDA) is used to understand a dataset through statistical summaries and visualizations. The Titanic dataset is used to explore passenger information and identify patterns related to survival.

## Key Techniques

- **Data inspection:** Examine dataset structure, column names, data types, and sample records.
- **Statistical analysis:** Summarize numerical features using descriptive statistics.
- **Categorical analysis:** Count passengers by survival status, gender, passenger class, and embarkation town.
- **Data filtering:** Select passengers based on conditions, such as age below 20.
- **Missing value analysis:** Identify and visualize missing values using null counts and heatmaps.
- **Data visualization:** Use count plots, pie charts, histograms, and scatter plots to understand distributions and relationships.
- **Survival analysis:** Compare survival patterns by gender and passenger class.

## Dataset

- **File:** `titanic.csv`
- **Features:** Survival status, passenger class, gender, age, fare, passenger category, and embarkation town, along with other passenger details.
- **Purpose:** Explore passenger characteristics and factors associated with survival.

## Typical Workflow

1. Load and inspect the Titanic dataset.
2. Examine sample records and statistical summaries.
3. Analyze passenger categories and survival counts.
4. Identify missing values.
5. Visualize distributions and relationships between features.
6. Compare survival across gender and passenger class.

## Tools

Python, Pandas, NumPy, Matplotlib, and Seaborn.

## Conclusion

EDA helps reveal patterns, distributions, missing data, and relationships within the Titanic dataset. These insights support better understanding of the data before further analysis or machine learning.
